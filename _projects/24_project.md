## Project Overview

Designed a **universal embedded systems learning kit** to simplify and accelerate the learning of embedded programming. The kit is compatible with four microcontroller families — **AVR, PIC, Arduino, and ARM** — and includes a rich set of onboard modules and interfaces so learners can immediately practice peripherals without any additional hardware. The entire kit is mounted on a **4-wheel robot chassis**, allowing students to also run motion and robotics experiments in addition to standard embedded programming exercises.

## Supported Microcontroller Families

| Platform | Interface |
|---|---|
| **Arduino** | Arduino Mega (ATmega2560) mounted on-board |
| **AVR** | DIP socket — ATmega8/16/32 compatible |
| **PIC** | DIP socket — PIC16F/PIC18F compatible |
| **ARM** | Header connector for ARM module |

---

## Onboard Modules & Interfaces

- **20×4 LCD Display** — character display for output and status
- **7-Segment Display** — numeric output for counter and value display exercises
- **Ultrasonic Sensor (HC-SR04)** — mounted on a servo for distance measurement and scanning
- **Servo Motor** — position control exercises
- **4×4 Keypad Matrix** — user input interface
- **Relay Module** — high-power load switching exercises
- **Motor Driver** — DC motor speed and direction control via the robot chassis wheels
- **RS232 (DB9)** — serial communication exercises
- **Breadboard Area** — custom circuit prototyping space
- **Screw Terminals** — external sensor and actuator connections
- **4-Wheel Robot Chassis** — enables motion control, obstacle avoidance, and line-following experiments

---

## Learning Applications

The kit covers the full embedded systems curriculum:

1. **GPIO** — LED blinking, button input, keypad scanning
2. **Timers & PWM** — servo control, motor speed, tone generation
3. **ADC** — analog sensor reading and conversion
4. **UART / Serial** — RS232 communication, PC terminal exercises
5. **LCD & Display** — 20×4 character LCD, 7-segment driver
6. **Sensors** — ultrasonic distance measurement with servo scanning
7. **Relays** — high-power switching and control
8. **Robotics** — motor control, obstacle avoidance, autonomous navigation
